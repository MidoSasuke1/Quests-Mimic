# 🎮 Quests Mimic

A lightweight, standalone universal activity simulator designed to complete desktop play quests effortlessly.

Developed with ❤️ by **[Mido Sasuke](https://github.com/MidoSasuke1)**.

---

## ✨ Features
- 🚀 **Zero Installation Required:** Standalone single executable.
- 📂 **3,500+ Verified Games:** Sourced directly from official detectable game registries.
- ⏱ **Custom Timers:** Select from 5m, 10m, 15m (default), 20m, or 30m.
- 🔔 **Custom Audio Alert:** Plays a clean sound notification upon quest completion.
- 🎨 **Modern Dark UI:** Responsive, Discord-inspired aesthetic built with CustomTkinter.
- ⚡ **Instant Search:** High-performance in-memory database filtering.
