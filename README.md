# 🎮 Quests Mimic

A lightweight, standalone universal activity simulator designed to complete desktop play quests effortlessly.

Developed with ❤️ by **[Mido Sasuke](https://github.com/MidoSasuke1)**.

---

## ✨ Features
- 🚀 **Zero Installation Required:** One standalone `.exe` — nothing to install, no dependencies to download. Just run it.
- 📂 **10,000+ Verified Games:** Sourced directly from Discord's official detectable game registry, with a one-click **Sync** to refresh the list.
- ⚡ **Smooth, Modern UI:** A fast, fluid, Discord-inspired dark interface with instant search.
- 🔁 **Sequential or Simultaneous:** Run games one after another, or all at once.
- ⏱ **Custom Timers:** 5m, 10m, 15m (default), 20m, or 30m per game.
- 🔔 **Completion Alert:** A clean sound and taskbar flash when your quests finish.
- 🔄 **Built-in Update Check:** Tells you when a newer version is available.

---

## 📥 Download
Download the latest standalone executable from the **[Releases](https://github.com/MidoSasuke1/Quests-Mimic/releases)** section.
